## 🎯 Objetivo

El objetivo de este proyecto es aplicar conocimientos de análisis de datos utilizando Python y Pandas, junto con buenas prácticas de desarrollo como versionado con Git, organización del código y limpieza de datos.

Se busca transformar un dataset con inconsistencias en información confiable para su posterior análisis.

---

## 🌍 Introducción y Contexto

La localidad de Vaalserberg (Bélgica), ubicada en una zona fronteriza entre Países Bajos y Alemania, cuenta con un sistema de radares urbanos que registra infracciones por exceso de velocidad.

Los datos históricos provienen de sistemas heredados, los cuales presentan problemas como:

- Formatos inconsistentes
- Datos faltantes
- Errores en registros

Este proyecto tiene como finalidad limpiar, normalizar y analizar estos datos para obtener información útil y facilitar su integración en sistemas modernos.

---

## 🛠️ Alcance del Sprint 1

Durante este sprint se desarrollan las siguientes tareas:

- Carga y exploración del dataset
- Limpieza y normalización de datos
- Eliminación de valores inválidos y outliers
- Cálculo de métricas de velocidad
- Análisis mediante clase `FineAnalyzer`
- Visualización de datos mediante gráficos
